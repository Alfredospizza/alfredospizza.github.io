# Portfolio

Static portfolio site, served by GitHub Pages at https://alfredospizza.github.io

Four working demos you can try on the page: an AI shop assistant that answers only from the shop's guide (its search runs in your browser, no AI model on the page), a Telegram booking Mini App, a replay of a real scraper run (1,000 products to Excel in 59 seconds) and a replay of a one-script Linux deployment with a crash test and HTTPS. Each one links to the recording of the real demo.

Optional "Full experience": a 90-second autopiloted 3D film of the four demos (three.js), with a generated synthwave score (Web Audio API), the browser's own voice reading the subtitles and an opening question answered by typing or by voice. It loads only when a visitor chooses it.

Plain HTML, CSS and JavaScript with no build step: `index.html`, `style.css`, `app.js`, and the film in `xp/`. Images and videos live in `assets/`. `/upwork/` is the same page with Upwork as the only hire link.
