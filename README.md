# Portfolio

Static portfolio site, served by GitHub Pages at https://alfredospizza.github.io

Four working demos: an AI chatbot that answers from a shop's own guide (RAG), a Telegram bot with a booking Mini App, a Python scraper that exports 1,000 products to Excel in 59 seconds, and a one-script Linux VPS deployment with HTTPS and backups.

Everything is plain HTML and CSS in `index.html`; images and videos live in `assets/`.
